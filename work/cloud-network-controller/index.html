Mapping cloud network configuration

I built a Terraform collection service that fed configuration into a graph database for Cloud APIC / Cloud Network Controller.

Python / Terraform / Dgraph / Cloud networking

The problem

A network model needs to represent cloud resources and the relationships between them, so configuration can be understood in context.

My contribution

I built the Terraform collection service as part of the cloud networking work. It fed collected configuration into Dgraph, representing resources and their relationships in the broader network model.

What it enables

The graph makes collected configuration available to the broader network model for analysis alongside relationships between resources.

Team context

The collection service was one contribution to the Cloud Network Controller product. The product and overall architecture were team work.
