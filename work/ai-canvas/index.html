Featured work

Agent execution and session coordination

I built the AgentCore integration and a custom sandbox image connecting isolated agent execution to the AI Canvas runtime.

AgentCore / Redis / Temporal / Containers

The problem

Sandbox execution separates the agent runtime from orchestration and session state. Those boundaries need coordination when requests overlap or an orchestrator stops.

My contribution

I built the AgentCore management integration and the sandbox image, and worked on the orchestrator’s session management and distributed task coordination using Redis and Temporal. The wider AI Canvas platform and architecture were shared team work.

Engineering focus

The work required explicit boundaries between orchestration and sandbox execution, alongside session ownership and coordination across services. The sandbox isolates execution, while the surrounding services coordinate state and tasks.

Validation

I terminated orchestrator pods during active queries to examine session continuity and routing across instances. This exercised a disruption path alongside normal execution; it does not by itself establish an availability or recovery guarantee.

What the work enables

The integration and image support isolated agent execution, with session coordination managed by the surrounding runtime services.
