03 / How I work

I test what happens
when things fail.

In AI Canvas, I terminated orchestrator pods during active queries to examine session continuity and routing. A successful request is only one part of the story.

  1. Make boundaries explicit.

    The AgentCore integration separates orchestration from sandbox execution. That isolation also introduces coordination between the runtime and the services managing it.

  2. Treat state as part of the design.

    My session-management work uses Redis and Temporal to coordinate tasks. When requests overlap, session ownership matters as much as the request handler.

  3. Exercise the disruption path.

    Stopping a pod during an active query tests behavior that the normal flow cannot reveal. I use that scenario to inspect continuity across orchestrator instances.
