Certificates and service coordination

I built certificate management and service coordination components within the Nexus Dashboard platform.

Kubernetes / Java / PKI / Postgres

The problem

Network management services need trusted communications and a shared way to coordinate active and standby instances.

My contribution

I worked on Kubernetes certificate management and external certificate authority integration for XE/XR device onboarding. I also implemented an SPI-based Java leader-election framework for active–standby configurations.

What it enables

Certificate automation supports CA creation, service signing, and external-CA onboarding. The reusable framework provides a coordination mechanism for services choosing an active instance.

Team context

These components were contributions within the Nexus Dashboard team; the broader product and infrastructure were developed collectively.
